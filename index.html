    About this board
    In demo mode every email is fictional and every address ends in the reserved .example TLD; nothing is fetched and nothing is sent. Connected, the board reads two JSON files from your private repo through the GitHub Contents API and can flip one switch in config.json.
    Not verified here
    The scheduled classifier runs in your own repo (a template is in template/); the board cannot see whether it ran. Category quality depends on the model and on subject lines alone. The digest is capped by keep_items, so the board never shows more than that many emails.
