还没配置 —— 三步开通（一次性，约 5 分钟）：
① Google 账号 → 安全 → 开启两步验证 → 搜「应用专用密码 App passwords」→ 生成一个（16 位）。
② GitHub 打开 Database 仓库 → Settings → Secrets and variables → Actions → 添加两条 Secret：GMAIL_USER=Gmail 地址、GMAIL_APP_PASSWORD=那 16 位密码。
③ Database 仓库 → Actions → 「Mail Classify」→ Run workflow：想把现有收件箱一次整理完，在 backfill_days 填天数（如 365）；留空只处理最近 7 天。之后每天早上自动分拣新邮件。
